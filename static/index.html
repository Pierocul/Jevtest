📨 Triaje de mensajes

Cada mensaje de cliente pasa por Jev: tipo (Choice), spam (Noul) y urgencia (Score) en una sola llamada. Toca un mensaje para ver su respuesta JSON.

MENSAJES DE CLIENTES
Toca «Probar ejemplos» o escribe tu propio mensaje. Cada mensaje pasa por Jev y aparece aquí con su clasificación.
from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

# Una llamada, tres preguntas tipadas.
response = client.system_one(
    state={"mensaje_del_cliente": mensaje},
    questions={
        "tipo": Choice(
            instructions="¿Qué tipo de mensaje es?",
            criteria={
                "consulta": "Pide información",
                "queja": "Reclama por un problema",
                "venta": "Quiere comprar",
                "otro": "Ninguna de las anteriores",
            },
        ),
        "spam": Noul(
            instructions="¿Es spam?",
        ),
        "urgencia": Score(
            instructions="¿Qué tan urgente es?",
            criteria=["baja", "media", "alta"],
        ),
    },
)

# Tu código decide qué hacer:
if response.nouls["spam"].noul > 0.8:  descartar()
